# 🚀 Projeto Exemplo com Git

Bem-vindo ao repositório! Este é um projeto de exemplo criado para demonstrar o uso básico do Git e do GitHub, servindo como referência para boas práticas de versionamento.

## 📖 Sobre o Projeto

Este repositório reúne exemplos práticos de comandos e fluxos de trabalho com Git, ideal para quem está aprendendo controle de versão ou quer uma referência rápida do dia a dia.

## 🛠️ Tecnologias Usadas

- **Git** — sistema de controle de versão
- **GitHub** — hospedagem de repositórios remotos
- **Markdown** — formatação da documentação
